موقع كليتي — HTML و CSS منفصلان

الملفات:
- index.html: بنية الموقع ومحتواه.
- style.css: التنسيقات والألوان والتجاوب مع الجوال.
- assets/: ملفات الشعار.

التشغيل:
1. فك ضغط الملف.
2. افتح index.html في متصفحك.
3. أبقِ style.css ومجلد assets بجانب index.html كما هي.
